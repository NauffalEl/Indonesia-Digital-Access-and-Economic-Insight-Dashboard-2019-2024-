# Indonesia Digital Access & Economic Insight Dashboard

An interactive data analytics dashboard that visualizes digital access and economic indicators across Indonesian provinces from 2019 to 2024.

## Overview

This project analyzes regional differences in digital access and explores their relationship with economic performance using population, digital access, and GRDP per capita data.

## Key Features

- Provincial-level digital access analysis
- Yearly comparison from 2019–2024
- Population and GRDP per capita visualization
- Regional digital access disparity analysis
- Economic performance comparison
- Interactive data exploration

## Technologies

- Data Analytics
- Data Visualization
- Dashboard
- Statistical Analysis

## Dashboard

The dashboard provides a longitudinal view of digital access and economic indicators, helping users compare provinces, identify regional disparities, and explore development patterns.
